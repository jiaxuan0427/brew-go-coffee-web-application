# Brew & Go. Coffee Web Application

## Overview
Brew & Go. Coffee is a web application developed as part of the Web Technology Project at Swinburne University of Technology Sarawak.

The website was designed to provide Brew & Go. Coffee with an online presence for showcasing products, activities and supporting customer engagement and job applications.

## Technologies
- HTML
- CSS
- PHP
- MySQL
- XAMPP

## Key Features
### User Authentication
Only logged-in users can access the job application form.

### Form Validation
Required fields are validated before the application is processed.

### File Upload
Users can upload their CV and photo. The uploaded photo is restricted to a maximum size of 200KB.

### Database Integration
Application information is stored in a MySQL database for later retrieval by administrators.

### Application Confirmation
After successful submission, users receive a confirmation page showing their submitted information and a link to download their CV.
